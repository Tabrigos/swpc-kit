# Changelog

All notable changes to this project are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[semantic versioning](https://semver.org/).

## [Unreleased]

### Changed

- The agent skill follows the shared standard for library skills (schema 1).
  `python -m swpc_kit.skill check` compares a project's copy with the
  installed package by content hash, with line endings normalized, instead
  of by version, and reports a copy edited by hand.
- `python -m swpc_kit.skill install` needs `--target`, writes only into
  `.claude/skills/swpc-kit` or `.agents/skills/swpc-kit`, marks the copy with
  `.skill-libreria.json` (package, version, hash) and never replaces a
  directory without that marker. `--force` is gone.
- `references/api.md` is generated by the shared generator of library
  skills: one section per public module, with the signature of every parser
  (its default `source_url` is the product's URL) and of the client's
  transport types.
- `swpc_kit.codes` and `swpc_kit.export.geotiff` declare `__all__`.

### Removed

- `python -m swpc_kit.skill sync` and the `agent_skills` entry point: skills
  are no longer discovered among the installed packages. A project lists the
  libraries it wants, copies their skills and keeps the copies in git.

## [0.2.0] - 2026-10-17

Never published or tagged: the first release on PyPI comes after it. This
section was changed after its date, while the version was still unpublished.

### Added

- An agent skill bundled with the package (`swpc_kit/skill/swpc-kit/`): a
  hand-written `SKILL.md` guide for AI coding assistants and a
  `references/api.md` generated from the code by `tools/build_skill.py`.
- `python -m swpc_kit.skill install | check | show | path` to copy the skill
  where assistants look for it and to tell whether the copy is current.
- `python -m swpc_kit.skill sync`, meant for a `SessionStart` hook: brings the
  skills of every installed package that declares one in the `agent_skills`
  entry point group into `.claude/skills/`, updating and removing copies as
  packages change, in one line of output and without ever failing.
- The `agent_skills` entry point (`swpc-kit = "swpc_kit.skill"`).

## [0.1.0] - 2026-10-17

First version. Never published or tagged.

### Added

- Parsers (`swpc_kit.parse`) and frozen, typed models (`swpc_kit.models`) for
  the SWPC products of the first version:
  - indices: planetary K index (3-hour, forecast, 1-minute), Kyoto Dst, F10.7
    (30 days), NOAA space weather scales; the pre-2026 array-of-arrays
    formats are read too and give the same models;
  - real-time solar wind (magnetic field and plasma) with active-source
    selection; GOES X-ray flux with flare class and integral protons;
  - `alerts.json` messages, and the catalogue of message codes
    (`swpc_kit.codes`) checked against the official SWPC table;
  - text bulletins: 3-day forecast, geomagnetic forecast, 27-day outlook;
  - OVATION aurora and D-RAP grids in a common grid model.
- Typed errors under `SwpcError`: `SourceNotReady`, `UnexpectedContent`,
  `ParseError`, `StaleData`.
- GeoJSON export (`swpc_kit.export.to_geojson`, standard library) and GeoTIFF
  export (`swpc_kit.export.geotiff.write_geotiff`, `geo` extra: numpy,
  rasterio).
- Sync and async HTTP clients (`swpc_kit.client`, `client` extra: httpx2) with
  one method per product, conditional requests (`ETag`, `Last-Modified`),
  error classification and a `max_age` check on the time the content
  declares.
- Recorded fixtures and the tools that record them (`tools/`).
